# Предметная область "Школа" (Основы ООП)

Данный проект демонстрирует ключевые принципы объектно-ориентированного программирования (ООП) на языке C++. В качестве предметной области выбрана структура школы.

## Реализованные концепции ООП

В коде наглядно и минималистично продемонстрированы 5 основополагающих отношений между объектами:

1. **Иерархия наследования** (Отношение "*is-a*")
   - Базовый класс: `Person` (Человек)
   - Наследник 1-го уровня: `Employee` (Сотрудник)
   - Наследник 2-го уровня: `Teacher` (Учитель)
   *Классы используют виртуальные методы (`info()`) для поддержки полиморфизма.*

2. **Ассоциация** (Слабая независимая связь)
   - Классы: `Student` (Ученик) и `Teacher` (Учитель)
   - Сущности существуют независимо друг от друга. Ученик просто хранит указатель на своего классного руководителя. Уничтожение ученика не влечет за собой уничтожения учителя и наоборот.

3. **Агрегация** (Отношение "*has-a*", независимое время жизни)
   - Классы: `School` (Школа) и `Teacher` (Учитель)
   - Школа имеет коллекцию учителей (хранит указатели на объекты). При закрытии или сносе здания школы (`~School()`) сами объекты учителей остаются в памяти программы и продолжают "жить".

4. **Композиция** (Отношение "*part-of*", жестко связанное время жизни)
   - Классы: `School` (Школа) и `Classroom` (Аудитория)
   - Школа физически содержит в себе помещения. Аудитории конструируются в момент постройки школы (вызов `new` в конструкторе `School()`) и безвозвратно уничтожаются при её сносе (вызов `delete` в деструкторе `~School()`).

5. **Делегирование** (Передача ответственности)
   - Метод: `conductLessons()` в классе `School`
   - Класс "Школа" не реализует логику преподавания внутри себя. Она формулирует задачу и полностью делегирует (поручает) её выполнение объектам учителей, вызывая у них метод `teach()`.

## Сборка и запуск проекта

Проект использует утилиту `make` для автоматической сборки. Компиляция выполняется компилятором `g++` с поддержкой стандарта `c++17`.

### Доступные команды:

- **Собрать и сразу запустить проект** (рекомендуется):
  ```bash
  make run
  ```

- **Только скомпилировать проект** (создаст исполняемый файл `./school_app`):
  ```bash
  make
  ```

- **Очистить директорию от временных файлов и бинарника:**
  ```bash
  make clean
  ```

## Структура фалов

- `Person.hpp` — Иерархия (люди, сотрудники, учителя).
- `Student.hpp` — Класс ученика (демонстрация ассоциации).
- `Classroom.hpp` — Класс аудитории (демонстрация композиции).
- `School.hpp` / `School.cpp` — Класс школы (агрегация, композиция, делегирование).
- `main.cpp` — Точка входа в программу. Содержит сценарий, создающий объекты и печатающий в консоль доказательства корректной связи жизненных циклов.
- `Makefile` — Скрипт сборки.
