# Лабораторная работа 2: Иерархия классов и полиморфизм

Проект дорабатывает библиотеку из ЛР1: добавлена иерархия классов (базовый `GeoLocation` и производный `Landmark`), полиморфная функция и функция вывода маршрута между точками. В приложении также реализована функция `move`, работающая с базовым классом изолированно от классов-потомков.

## Описание

### Класс GeoLocation (без изменений)
Хранит географические координаты (широту и долготу) и предоставляет:
- вычисление расстояния по формуле Хаверсина (км);
- статический метод перевода из формата DMS (градусы/минуты/секунды) в десятичный формат;
- определение полушария, проверку корректности координат;
- перегрузку операторов `==`, `!=` и вывода в поток `<<`.

### Класс Landmark (расширение)
Наследуется от `GeoLocation`, добавляет:
- поле **name** — название ориентира;
- переопределённый оператор **<<** — выводит название и координаты в формате `"Название: (lat, lon)"`.

### Функция printRoute
`void printRoute(GeoLocation from, GeoLocation to)` — выводит информацию о маршруте:
- начальная и конечная точки (координаты и полушарие);
- расстояние между ними в км.

### Полиморфная функция
В приложении реализована перегруженная функция `printLocationInfo`:
- для `GeoLocation` выводит строку вида «Точка: (lat, lon)»;
- для `Landmark` — «Ориентир: Название: (lat, lon)».

Демонстрируется вызов с объектами базового и производного классов.

### Функция move
`void move(GeoLocation& loc, double newLat, double newLon)` — принимает объект **по ссылке на базовый класс** (не знает о классах-потомках):
- устанавливает новые координаты через методы базового класса (`setLatitude`, `setLongitude`);
- печатает итоговое состояние объекта.

При передаче объекта-наследника (`Landmark`) срезки не происходит; собственные поля наследника (например, `name`) остаются нетронутыми.

## Структура проекта

| Файл | Назначение |
|------|------------|
| `GeoLocation.h` | Интерфейс класса GeoLocation |
| `GeoLocation.cpp` | Реализация GeoLocation |
| `Landmark.h` | Интерфейс Landmark и объявление printRoute |
| `Landmark.cpp` | Реализация Landmark и printRoute |
| `main.cpp` | Демонстрационное приложение |
| `Makefile` | Сборка статической библиотеки и исполняемого файла |

Библиотека: `libgeolocation.a` (собирается из `GeoLocation.cpp` и `Landmark.cpp`).

## Сборка и запуск

```bash
# Сборка и запуск
make run

# Только сборка
make

# Очистка
make clean
```
