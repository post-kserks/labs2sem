# Лабораторная работа 1: Статическая библиотека GeoLocation

Этот проект представляет собой реализацию кроссплатформенной статической библиотеки на C++ для работы с географическими координатами, а также демонстрационное приложение.

## Описание

Класс `GeoLocation` позволяет хранить координаты (широту и долготу) и выполнять с ними различные операции.

### Основные возможности:
- **Вычисление расстояния**: Реализовано через формулу Хаверсина (расстояние между двумя точками на сфере в км).
- **Поддержка DMS**: Статический метод для перевода координат из формата Градусы/Минуты/Секунды в десятичный формат.
- **Определение полушария**: Методы для получения информации о том, в каком полушарии находится точка.
- **Перегрузка операторов**: Реализованы операторы сравнения (`==`, `!=`) и вывода в поток (`<<`).

## Структура проекта

- `GeoLocation.h` — Заголовочный файл с описанием класса.
- `GeoLocation.cpp` — Реализация методов класса.
- `main.cpp` — Демонстрационное приложение, использующее библиотеку.
- `Makefile` — Скрипт для сборки проекта.

## Сборка и запуск

Для сборки проекта и запуска демо-версии используйте `make`:

```bash
# Сборка и запуск одним шагом
make run

# Сборка только библиотеки и исполняемого файла
make

# Очистка временных файлов
make clean
```
